## PharmaLynx-POS

## Project Overview

PharmaLynx is a comprehensive Pharmacy Point of Sale (POS) system designed to streamline operations for pharmacies. It offers robust features for managing sales, inventory, users, and prescriptions, along with advanced functionalities like PWA support and an AI-powered chatbot for enhanced efficiency and customer service.

## Features

*   **Sales Management**: Efficiently process sales, generate receipts, and manage transactions.
*   **Inventory Management**: Track medicine stock, manage expiry dates, and receive low-stock alerts.
*   **User Management**: Secure user authentication with role-based access control for administrators and staff.
*   **Prescription Management**: Handle prescription details and generation.
*   **Reporting**: Generate various reports, including sales summaries and medicine insights.
*   **Progressive Web App (PWA)**: Provides an installable, app-like experience with offline capabilities.
*   **AI Chatbot Integration**: An intelligent assistant for quick queries on stock, expiring medicines, sales, and AI-driven image generation for medicines.
*   **Database Management**: MySQL database for reliable data storage.

## Technologies Used

The project leverages a combination of modern web technologies:

*   **Backend**: PHP (with PDO for database interaction)
*   **Database**: MySQL
*   **Frontend**: HTML5, CSS3, JavaScript
*   **Frameworks/Libraries**: Bootstrap, Chart.js
*   **PWA**: Service Workers, Web App Manifest
*   **AI Integration**: Pollinations.ai (for image generation), FDA API (for external medicine info)

## PWA Support

PharmaLynx POS is a Progressive Web App, offering a native app-like experience. You can install it directly from your browser on supported devices. 

## Chatbot Integration

The integrated AI Chatbot provides instant assistance for various tasks:

*   **Stock Inquiry**: Ask about medicine quantities.
*   **Expiry Alerts**: Get information on medicines nearing expiry.
*   **Sales Data**: Summaries of daily sales.
*   **Medicine Information**: Search for details on specific medicines.
*   **Image Generation**: Request AI-generated images of medicines
